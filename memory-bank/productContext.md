# 產品脈絡

## 為什麼

字幕組用 kara-templater 做卡拉 OK 特效，每次都要開 Aegisub GUI 套用、存檔。這個工具讓同樣的事能在命令列、
批次與測試裡做，並且結果與 Aegisub 完全相同，才能放心取代 GUI 操作或拿來驗證重構後的模板。

## 使用方式（重點）

- `aegisub-render.py render in.ass`：預設套用 kara-templater 後**覆寫輸入檔**（等同 Apply 後存檔）。
- `-o PATH` 寫到別處；已存在時預設詢問，`-y/--override` 直接覆寫、`-n/--no-override` 不覆寫並以錯誤結束
  （在執行腳本前就決定）。`-o -` 寫到 stdout（忽略 -y/-n）。
- `--dry-run`：什麼都不寫，把「輸入 → 結果」的 unified diff 印到 stderr（`;` 開頭的行不比較；沒有差異時印
  `No differences found.`）。
- `--filter NAME`：執行匯出濾鏡，像 File → Export 一樣寫出（沒有 Project Garbage／Extradata；但輸入本來有的話保留）。
- `--macro NAME`、`--script`、`--select`、`--force`（validation 回傳 false 時仍執行；否則只印一行說明）。
- 進度條：stderr 是終端機時用 tqdm 顯示，結束後留在畫面上（成功補到 100%）。
- `scripts/build_exe.py` 產生 `aegisub-render.exe`（distlib 啟動器包裝 `.venv\Scripts\python.exe aegisub-render.py`，
  內含絕對路徑，repo 或 .venv 搬家後要重建；已 gitignore）。

## 行為上的決定（使用者明確要求過的）

- 沒能載入的連結檔（影片／音訊／時間碼／關鍵影格不存在、`--no-video`、`--fps`）**保留**在 Project Garbage，
  不像 Aegisub 存檔時刪掉；存到別的目錄時改寫相對路徑（Aegisub 另存新檔的行為）。
- 輸出 header：`; Script generated by Aegisub <ver> with aegisub-render <ver>` 接 `; https://aegisub.org/`。
- `aegisub.clipboard` 報「unreachable」；`aegisub.lfs` 照原樣；`set_status_text` 印到 stderr；
  `get_audio_selection` 拋未實現錯誤；沒有影片時照原版回傳 nil／`{}`。
- 字型被 GDI 替換時警告，但樣式用的是字型任一語言的名稱（例如英文名、系統是中文）時不算替換。
