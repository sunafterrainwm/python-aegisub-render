# 踩過的坑（動手之前先看）

全部是在實際做完的 OP／ED 專案裡撞到的，不是從文件抄的。

## libass

- **零長度的行會讓 libass 漏畫其他行。** 模板不要產生 `0:00:00.00,0:00:00.00` 的 fx 行；
  需要「這一格不畫」時輸出一個透明的小圖形，不要讓時間收成空區間。
  （有一次整個片名消失就是這個，二分法找了很久。）
- **libass 會把繪圖的外框對齊定位點**，負座標會被整個平移。以中心為原點畫的圖形要先正規化到
  左上角 (0,0)（`nz()`）再輸出。
- **`\an7` 繪圖的原點就是 `\pos`**，與 bounding box 無關。圖形一律 `\an7` ＋自訂原點來畫。
- **`\p1` 繪圖會被樣式的 ScaleX／ScaleY 縮放**。credit 樣式常用 65～82%，所以繪圖輸出都要補
  `\fscx100\fscy100`。
- **`\fry` 的透視非常重**：實測透視距離只有約 312 px（20000/64）。寬 900px 的長條轉 30° 就嚴重變形。
  要做「翻牌」用 `\frx`（繞水平軸），深度只有半個長條高。
- **字身只有在 `\bord0` 且 `\shad0` 時才會被 `\blur` 影響**，所以「糊的字芯 ＋ 清楚的白邊」一定要分層畫。
- **`\fad` 會把 `\4a` 一起蓋掉**。有陰影的層一律用 `\t` 自己控 `\1a\3a\4a`。
- 動畫 `\clip` 的矩形可以放進 `\t`，畫線／擦線的動畫靠它。
- **Noto Sans CJK 的實際字身約為字級的 0.69 倍**（行高＝ascent＋descent）。

## kara-templater／karaskel

- **`code`／`template` 行必須在 `[Events]` 的前 50 行內**，否則巨集的 validation 回傳 false，
  Aegisub 會把選單變灰。這個 skill 的工具**不提供繞過的選項**（`ScriptRender` 不傳 `force=`），
  validation 不過就直接失敗——交付檔必須是「在 Aegisub 裡按下去就會動」的檔案。
- **沒有 `\k` 的行只有一個長度 0 的音節**：`template syl`／`template char` 帶 `noblank` 時整行被跳過，
  不帶時所有字擠在同一個時間點；`template line` 不受影響。所以套逐音節／逐字模板的行要有 `{\k…}`，
  只套整行模板的行（例如只做整句進退場的中文行）不需要。實測表見 `timing.md` 的「哪些行需要 `\k`」。
  只分段不切軸的 `\k` 取「一幀的毫秒數」四捨五入（`round(1000/fps)`：24000/1001 → 42、30000/1001 → 33、25 → 40），整首一致。
- **`template line` 的主體會對每個音節各跑一次再串接**。整行只出現一次的元素要用
  `ONE(syl, f, ...)` 這種守門函式，只在第一個音節輸出。
- **`template char` 時 `syl.width` 還是整個音節的寬度**，單一個字要用 `syl.right - syl.left`。
- **模板環境沒有 `type`、`tonumber`、`ipairs` 等全域** → `code once` 開頭從 `_G` 帶進來。
- **`aegisub.text_extents` 的樣式表必須是真的樣式物件**（`class='style'`…）。
  要換字型量字就 `table.copy(line.styleref)` 再改 `fontname`。
- **`syl.left/center/right` 是相對行首**，絕對座標要加 `line.left`。`line.x`／`line.y` 的意思
  隨對齊改變，不要用。
- **`$變數` 都是取整數**，要小數就直接用 Lua 物件（`syl.left` 而不是 `$sleft`）。
- **Name 與 Effect 欄位不能有逗號**（ASS 用逗號分欄）。
- **每次渲染都會重建 `<樣式>-furigana`**；改了母樣式就把舊的刪掉讓它重生。
- `meta.res_y` 可取得 PlayResY（做上下鏡像時要用）。
- **Lua 裡不能用 `--` 行註解**：區塊會被接成一行，行尾的 `--` 會把後面全部吃掉。
  說明寫在區塊開頭，由工具轉成 `--[[ ]]`。

## 時間

- **時間要先捨到 10ms 再寫成時間碼**。ASS 只到 1/100 秒；直接拆「秒」與「毫秒百分位」會寫出
  `0:00:10.100` 這種東西。而且行的起點被捨掉幾 ms 的話，行內 `\t` 的相對時間就跟著差那幾 ms。
  用 `ass_formatted(ms)` 就不會錯。
- **NC 版的對應用影格數表示，不要用毫秒**：毫秒換算會差一格，一格就看得出來。
- **亂數種子如果含行的開始時間**，NC 版平移之後抖動角度、顆粒位置會和本篇不同。
  要讓兩版一致就改用「文本雜湊＋長度（格數）＋樣式＋字的位置」當種子。

## 量測

- **優先用 `measure_text()`**（見 `api.md`）。真的要用 libass 畫出來數像素時：
  - **不要帶 `\blur`**，模糊會讓偵測到的範圍往外擴一兩 px；
  - **門檻要分清楚**：`>24` 會把柔光也算進去，量字身要用 `>100`；
  - 量單獨一層時先把其他 Dialogue 行濾掉再畫。
- 二值化的 IoU 對 2～4px 的細線是很差的指標（1px 的對位差能讓 IoU 從 0.56 跳到 0.75）。
  比對形狀要看紅藍疊圖，不要只看數字。

- **樣式的字型沒裝時，量字和燒字會退到不同的替代字型。** `aegisub.text_extents`（fontconfig／GDI）
  選到的替代字型可能連 CJK 字都沒有，libass 卻會再退到有字的那一個：模板照前者的寬度排位置、
  畫面照後者畫，結果每個詞互相重疊。`verify.py` 會列出缺的字型；`measure.py … --ink` 可以看到
  量到的寬度和實際畫出來的差多少。解法依序是：裝字型 → `--font-dir` 指到放字型的資料夾 →
  真的拿不到（商用字型）時寫一份 fontconfig 設定把它對應到同一個替代字型，渲染與燒字都帶
  `FONTCONFIG_FILE=…`，讓兩邊退到同一個字。最後一種做出來的座標是替代字型的，
  交付時要講明「要在裝有該字型的機器上重新套用一次模板」，而且那台機器上 `verify.py` 的
  「最新」本來就會不同，不是壞掉。

## ffmpeg

- **filtergraph 會把 Windows 磁碟機代號的冒號當成參數分隔**。`subtitles=` 要嘛 `cwd` 切到該資料夾
  再傳純檔名，要嘛跳脫。`scripts/frames.py` 的做法是把 .ass 複製到暫存資料夾用簡單檔名跑，
  順便避開中文與方括號（`subtitles=` 對它們也會出事）。
- **`-ss` 之後要 `-copyts`**，`subtitles` 濾鏡才看得到真正的時間；或者用
  `setpts=PTS+T/TB`（快速 seek 又保住時間軸）。
- **要限制長度時 `-t` 必須放在 `-i` 之前**，放在後面會因 `copyts` 輸出空檔。

## 編碼與 shell

- **呼叫 Python 一律 `-X utf8`／`PYTHONUTF8=1`，開檔明確寫 `encoding="utf-8"`。**
  這台機器 locale 是 cp950：讀 UTF-8 會炸，寫檔會**靜默地**把破折號與 CJK 轉成 cp950。
- **絕對不要讓帶反斜線的內容經過 shell heredoc**：`\\an5` 會變 `\an5`、`\n` 變成真的換行、
  `\b` 變成 0x08。含標籤或正規式的 Python／Lua 片段一律用 Write／Edit 工具寫成檔案。
  （這個坑在一個專案裡踩了至少四次。）
- **`Path.read_text()` 會把 CRLF 正規化成 `\n`**，所以用 `"\r\n"` 切行會整個檔變成一行，
  替換全部失效而且不會報錯。用 `AssFile` 讀就沒有這個問題。

## 改別人的工作檔

**一定要先拿副本試跑再比對。** 對方（委託方、其他譯者）會在他們的 `Template.ass` 上做在地修改，
整批覆蓋會把它們洗掉。他們匯入時也可能把 `--[[ ]]` 註解拿掉，比對要先把註解剝掉再比，
否則會看到幾百行「都變了」。
